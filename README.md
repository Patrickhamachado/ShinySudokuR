
# Enjoy playing Sudoku in Shiny!
[Connect Cloud App]([https://duckduckgo.com](https://01a146b3-8a06-bb54-5bbd-2b85de794f48.share.connect.posit.cloud/))

### Instructions:

1. Select the number you want to use for filling or marking in the upper selection buttons

    **TIP:** Pres a number in the keyboard to select it

2. In the button "Action" select if you want to Fill or Mark

    **TIP:** Pres [Ctrl] or [Shift] in the keyboard to toggle the selection

3. Click in the field you want to fill or mark with the selected number  

4. Enjoy!
